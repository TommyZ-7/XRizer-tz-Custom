# XRizer AA B1b (FXAA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an equal-size FXAA Quality pass with the three weight modes, compare, preserve-alpha, and the radius debug contour.

**Architecture:** Replace the pass-through `upscaler.vert`/`upscaler.frag` pair with a simple full-screen `aa.vert` and an edge-directed FXAA fragment shader. The Rust pipeline carries the AA parameters in a compact push-constant block; the CPU config and tests remain in `src/upscaler`.

**Tech Stack:** Rust 2024, ash/Vulkan, GLSL 450, `glslc`.

**Spec:** `docs/contracts/settings-v1.md` in the config worktree and the B1a plan.

## Global Constraints

- Output extent equals input extent.
- FXAA is the only implemented method in B1b. `cmaa2` and `smaa` fall back to FXAA until B2/B3.
- B1b's temporary default is `fxaa`; B2 flips the default to `cmaa2`.
- `weight_mode` is `center`, `inverted`, or `whole`; default `inverted`.
- `preserve_alpha` bypasses AA for alpha < 0.999.
- `compare` toggles only the AA effect.
- `show_region` draws the `radius` contour for `center`/`inverted`, not `whole`.
- Run `cargo fmt --check`, `cargo clippy --workspace --all-targets`, `cargo test`, `cargo xbuild`.

## Review Focus

- FXAA search must not sample outside the source bounds.
- `whole` mode must ignore `radius`/`feather`.
- Alpha-preserved pixels must keep both colour and alpha.
- Compare-off must return the original pixel exactly.
- The push-constant layout must match between Rust and both shaders.

### Task 2: FXAA shaders and pipeline

**Interfaces:**
- Produces: `AaPushConstants` layout:
  `src_bounds: vec4`, `center: vec2`, `radius: f32`, `feather: f32`,
  `strength: f32`, `flags: u32`, `dst_width: u32`, `dst_height: u32`,
  `weight_mode: u32`, `antialias: u32`, `fxaa_quality: u32`, `smaa_threshold: f32`.
- Produces: `UpscalerPipeline` uses `aa.vert` + `fxaa.frag` and a fragment-stage push-constant range.

- [ ] **Step 1: Add `aa.vert`**

```glsl
#version 450

layout(location = 0) out vec2 v_uv;

void main() {
    vec2 uv = vec2((gl_VertexIndex << 1) & 2, gl_VertexIndex & 2);
    v_uv = uv;
    gl_Position = vec4(uv * 2.0 - 1.0, 0.0, 1.0);
}
```

- [ ] **Step 2: Add `fxaa.frag`**

Use an FXAA-style edge-directed filter:

- sample the source at `mix(src_bounds.xy, src_bounds.zw, v_uv)`;
- compute luma from the 3x3 neighbourhood;
- early-out on low contrast;
- choose the edge direction from luma gradients;
- search 2/4/8 steps along the edge based on `fxaa_quality`;
- blend the two edge taps;
- compute the weight field with the same formulas as `weight_at_mode`;
- `mix(original, filtered, weight * strength)`;
- return the original pixel when `(flags & FLAG_ENHANCEMENT_ENABLED) == 0` or alpha < 0.999;
- draw a magenta `radius` contour when `(flags & FLAG_SHOW_REGION) != 0` and `weight_mode != 2`.

- [ ] **Step 3: Update the shader list**

Replace `upscaler.vert`/`upscaler.frag` with `aa.vert`/`fxaa.frag` in `shaders/src/lib.rs`.

- [ ] **Step 4: Update the Rust push constants and pipeline**

- Replace the old `PushConstants` with the 64-byte layout above.
- Set the push-constant range to `ShaderStageFlags::FRAGMENT`.
- Bind `aa.vert` and `fxaa.frag`.
- Fill `center` from `params.center_for_eye(eye)`.
- Encode `weight_mode` as 0/1/2 and `antialias` as 0/1/2/3.
- Encode `fxaa_quality` as 0/1/2.
- `cmd_push_constants` uses `FRAGMENT`.

Expected: shader compilation and Rust build pass.
